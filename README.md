你可以预言任何数字（日期、时间、幸运数字等），让观众随机说两个数字进行计算，最终结果神奇地变成你预言的数字！

## 📱 完整表演流程

### 准备阶段（私下操作）

1. **确定目标数字**
   - 例如：当天的日期时间 `2162227`（2月16日22:27）
   - 或者任何你想预言的数字

2. **设置目标数字**
   - 在计算器中输入目标数字：`2162227`
   - **长按右上角空白区域 1 秒**
   - 屏幕会短暂闪烁，表示目标已设置
   - 按 `AC` 清空显示（目标数字已保存在后台）

3. **写下预言**
   - 在纸上写下：`2162227`
   - 折叠后交给观众保管

### 表演阶段（当众操作）

4. **让观众参与**
   - 对观众说："请随便说一个数字"
   - 观众 A 说：`1106`
   - 你在计算器输入：`1106` 然后按 `+`

5. **第二个随机数**
   - 对另一位观众说："你也说一个数字"
   - 观众 B 说：`88396`
   - 你输入：`88396` 然后按 `=`
   - 显示结果：`89,502`

6. **魔术时刻**
   - 说："这个数字还不够随机，让你们来按键盘"
   - **把手机屏幕向下，让观众随机按键盘**
   - 观众会听到按键声音，以为在输入数字
   - 实际上：你在递给观众前，**快速点击右上角空白区域**
   - 此时键盘已锁定，显示的是差值 `2,072,725`
   - 观众按任何数字键都不会改变显示

7. **揭晓奇迹**
   - 收回手机，说："让我们看看你们按出了什么"
   - 按 `=` 键
   - 显示：`2,162,227`
   - 让观众打开预言纸条，完全一致！

## 🎯 关键操作说明

### 秘密区域位置
- 位于屏幕**右上角**
- 大小约 80x80 像素
- 完全不可见，观众不会察觉

### 两种操作
| 操作 | 功能 | 反馈 |
|------|------|------|
| **长按 1 秒** | 设置目标数字 | 屏幕短暂闪烁 |
| **快速点击** | 计算差值并锁定键盘 | 显示差值 |

### 键盘锁定机制
- 点击右上角后，键盘自动锁定
- 所有数字键、AC、+/-、% 等按钮失效
- **只有等号键可以按**
- 观众按键会有触感和声音，但不会改变显示
- 按等号后显示目标数字，锁定自动解除

## 🚀 部署和安装

### 下载项目

**方法 1：使用 Git（推荐）**
```bash
# 克隆仓库
git clone <你的仓库地址>
cd magic-calculator

# 或者如果还没有创建仓库，直接下载文件
```

**方法 2：直接下载**
- 下载项目的 ZIP 文件
- 解压到本地文件夹
- 进入项目目录

### 本地测试

**方法 1：使用 Python（最简单）**
```bash
# 进入项目目录
cd magic-calculator

# 启动服务器
python3 -m http.server 8000

# 在浏览器打开
# http://localhost:8000
```

**方法 2：使用 Node.js**
```bash
# 进入项目目录
cd magic-calculator

# 使用 npx（无需安装，推荐）
npx serve

# 或者使用 http-server
npx http-server

# 或者全局安装后使用
npm install -g serve
serve

# 浏览器会自动打开，或手动访问显示的地址
# 通常是 http://localhost:3000 或 http://localhost:5000
```

**方法 3：使用 VS Code Live Server**
- 安装 VS Code 的 Live Server 扩展
- 右键点击 `index.html`
- 选择 "Open with Live Server"

### 手机测试

如果想在手机上测试：

```bash
# 1. 启动本地服务器（使用上面任一方法）

# 2. 查看电脑的局域网 IP
# macOS/Linux:
ifconfig | grep "inet "
# 或
ipconfig getifaddr en0

# Windows:
ipconfig

# 3. 在手机浏览器访问
# http://192.168.x.x:8000
# （将 192.168.x.x 替换为你的电脑 IP）
```

### 部署到 Vercel

**方法 1：使用 Vercel CLI**

4. 导入你的 Git 仓库

1. 访问 [vercel.com](https://vercel.com)

3. 自动开始部署

## 📞 问题排查

**Q: 点击右上角没反应？**
- 确保点击的是右上角区域（约 80x80 像素）
- 长按 1 秒设置目标，快速点击计算差值

**Q: 观众按键有反应怎么办？**
- 确保在递给观众前已点击右上角
- 检查控制台是否显示"键盘已锁定"

**Q: 如何重置？**
- 按等号完成魔术后，键盘自动解锁
- 按 AC 可以清空显示，但不会清除目标数字
- 重新长按右上角可以设置新的目标数字
